项目环境配置指南

一、先说明这个项目包含什么
本仓库大致分为 4 部分：
1. frontend：前端，Vue 3 + Vite
2. backend：后端，FastAPI + SQLAlchemy + MySQL
3. epf：电价预测相关脚本
4. market：市场出清/竞价策略相关脚本和数据

如果你的目标只是“把系统页面跑起来，并能正常登录、查看基础数据”，只需要先完成“基础运行环境”。
如果你的目标还包括“EPF 训练/自动选模/市场出清/竞价策略”，再继续配置“扩展环境”。


二、基础运行环境
建议在 Windows 下配置，和当前项目脚本更匹配。

需要安装：
1. Python 3.12
2. Node.js 18 或 20
3. MySQL 8.0
4. Git（可选，但建议安装）

建议版本：
1. Python：3.12.x
2. Node.js：18.20+ 或 20.x
3. npm：随 Node.js 一起安装
4. MySQL：8.0.x


三、目录要求
项目根目录应为：
E:\桌面\咸鱼\code\code

后续所有命令默认都在这个目录下执行，除非我特别说明要进入子目录。


四、MySQL 配置
1. 启动 MySQL 服务
2. 新建数据库 `dianli`
3. 确认数据库账号可用

推荐直接使用下面这组默认配置：
1. 数据库名：`dianli`
2. 用户名：`root`
3. 密码：`123456`
4. 地址：`127.0.0.1`
5. 端口：`3306`

如果你的 MySQL 不是这套配置，也可以，但必须同步修改 `backend\.env`

可参考 SQL：
CREATE DATABASE dianli DEFAULT CHARACTER SET utf8mb4;


五、后端环境配置
1. 进入后端目录
cd backend

2. 创建虚拟环境
python -m venv .venv

3. 激活虚拟环境
.venv\Scripts\activate

4. 安装依赖
pip install -r requirements.txt

5. 配置环境变量文件
后端会读取 `backend\.env`
当前仓库里已经有这个文件，默认内容如下：

MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DB=dianli
MYSQL_USER=root
MYSQL_PASSWORD=123456

如果你是从 0 拿到一个纯净仓库，没有 `.env`，就自己在 `backend` 目录下新建这个文件。

6. 启动后端
uvicorn app.main:app --reload~~~~~~~~~~~
python -m uvicorn app.main:app --host 127.0.0.1 --port 8001
python -m uvicorn app.main:app --host 127.0.0.1 --port 9011

启动后说明：
1. 后端地址：`http://127.0.0.1:8000`
2. 接口前缀：`/api`
3. 首次启动会自动建表、初始化管理员账号、并导入一部分基础数据

默认管理员账号：
1. 用户名：`admin`
2. 密码：`admin123`


六、前端环境配置
1. 新开一个终端
2. 进入前端目录
cd frontend

3. 安装依赖
npm install

4. 启动前端
npm run dev

启动后说明：
1. 前端地址：`http://localhost:5173`
2. 登录页：`http://localhost:5173/login`
3. 前端已配置代理，会把 `/api` 请求转发到 `http://127.0.0.1:8000`

所以前后端联调时，后端必须先启动。


七、最小跑通步骤
如果你只想先从 0 跑通项目，按下面顺序即可：

1. 安装 Python、Node.js、MySQL
2. 创建 MySQL 数据库 `dianli`
3. 配置并启动后端
4. 配置并启动前端
5. 浏览器打开 `http://localhost:5173/login`
6. 使用 `admin / admin123` 登录

到这一步，基础功能就算跑通了。


八、扩展环境：EPF 电价预测
如果你要使用以下功能，再继续配置这一部分：
1. 自动选模
2. EPF 训练
3. 概率预测结果读取

从代码实际依赖看，EPF 脚本至少还需要这些 Python 包：
1. pandas
2. numpy
3. matplotlib
4. scikit-learn
5. torch

建议做法：
1. 单独创建一个 Conda 环境，例如 `epf`
2. 安装上面这些包
3. 进入对应脚本目录后再执行

说明：
1. 仓库里目前没有单独提供 `epf` 的 `requirements.txt` 或 `environment.yml`
2. 也就是说，这部分依赖需要你手动补齐
3. 如果只跑前后端页面，不装这部分也能启动系统


九、扩展环境：market 市场出清/竞价策略
如果你要使用以下功能，再继续配置这一部分：
1. 竞价策略生成
2. 出清后评价
3. 市场出清批处理

除了后端已有的 `openpyxl` 外，这部分脚本从代码看还依赖：
1. pandas
2. numpy
3. matplotlib
4. scikit-learn
5. openpyxl

另外还有两个重要外部条件：
1. `market\main_da_market_V1.exe` 必须可运行
2. `market\config.ini` 里的求解器路径必须指向你机器上真实存在的求解器

当前 `market\config.ini` 里写的是：
1. `solver_name = gurobi`
2. `cplex_solver = D:\IBM\ILOG\CPLEX_Studio128\cplex\bin\x64_win64\cplex.exe`

这意味着：
1. 如果你要真正执行市场出清，通常还需要安装 Gurobi 或 CPLEX 一类求解器
2. 并按你本机安装路径修改 `market\config.ini`
3. 如果不跑市场出清，这部分可以先不配


十、常见问题
1. 后端启动报数据库连接失败
先检查 MySQL 是否启动，再检查 `backend\.env` 里的账号密码和库名是否正确。

2. 前端能打开，但接口报错
通常是后端没启动，或者后端启动失败。

3. 登录失败
先确认后端第一次启动时有没有成功执行建表和初始化；默认账号是 `admin / admin123`。

4. 页面开了，但部分预测/市场功能不可用
这通常不是前后端基础环境问题，而是 `epf` 或 `market` 的扩展依赖没装全。

5. README 提到 `.env.example`
当前仓库里我只看到 `backend\.env`，没有看到 `backend\.env.example`，所以直接使用或手动创建 `.env` 即可。


十一、推荐启动顺序
每次开发建议按这个顺序启动：

1. 先启动 MySQL
2. 再启动 backend
3. 最后启动 frontend


十二、你至少要准备好的软件清单
基础必装：
1. Python 3.12
2. Node.js 18/20
3. MySQL 8.0

按需安装：
1. Conda 或 Miniconda
2. pandas / numpy / matplotlib / scikit-learn / torch
3. Gurobi 或 CPLEX


十三、一套最常用命令汇总
后端：
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

前端：
cd frontend
npm install
npm run dev


十四、结论
如果你的目标是“从 0 开始先把项目跑起来”，最低只需要配好：
1. Python
2. Node.js
3. MySQL
4. backend\.env

然后启动后端和前端即可。

如果你后面还想把“预测训练”和“市场出清”也真正跑通，再继续补装 EPF 和 market 的扩展依赖。
